# 昆仑游戏工程预留目录

该目录预留给像素 2D 游戏开发，目前只完成目录准备。Godot 项目文件放在此目录，开发从输入、场景加载、角色移动和交互开始，随后接入对白、任务、存档与回合制战斗，剧情从序章按章节推进。

独立可玩样章不再作为前置开发步骤，华山故居按第 06 章的完整剧情制作。

| 目录 | 用途 |
| --- | --- |
| `scenes/` | 可运行的场景、界面和战斗舞台；子目录按具体场景建立 |
| `scripts/` | 场景所需脚本；与场景高度相关的脚本也可放在对应场景旁 |
| `data/` | 已统一 ID 和结算规则的章节、任务、技能、敌人数据 |
| `assets/` | 可导入引擎的像素图集、字体、音效与音乐 |

制作规格读取 [V3 美术模块](../docs/design/v3/08_像素美术资产全量清单.md)，先结合 [审阅报告](../docs/reviews/v3_numeric_review.md) 对齐地图预算、动作编号与分类锚点。根目录 `assets/concepts` 的华山图是视觉参考，不是已切图、含碰撞与导航的引擎资源。

工程组织可参考 [Godot 项目组织文档](https://docs.godotengine.org/en/stable/tutorials/best_practices/project_organization.html)。新增代码与引擎文件采用 `snake_case`，缓存和导出构建产物按根目录 `.gitignore` 管理。
