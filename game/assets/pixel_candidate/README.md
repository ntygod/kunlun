## 原创来源说明

这批由助手编写明确的像素字符网格、整数坐标轮廓与逐像素修饰，Pillow只作确定性的像素写入和PNG导出。所有轮廓/色块均可在源代码直接编辑。没有调用生成式图像模型，没有3D渲染、照片缩小、外部图像、第三方角色、下载的素材或噪声纹理。没有镜像、旋转、非整数缩放、模糊、渐变、抗锯齿；4倍预览仅使用最近邻。并非声称由人类美术师在绘画软件中逐笔完成。

视觉依据是用户已有 V3 原案：08 §1.2/1.3/1.4、EXP-01、EXP-09；梁天德依据02 SC-00-01/04的粗布老农、白发和隐忍军旅身份。没有把成年梁萧右肩行囊误用于十岁少年。

W/E面部、襟口和配件遮挡独立定义；少年左腰筒在E侧近景显露、W侧被身体遮挡，正面画面右方、背面画面左方。右衽的正面闭合落在人物右侧（画面左方）。折扇位于梁文靖左后，E/N可见更多，W为远侧，未配置运行时Flip_H。
