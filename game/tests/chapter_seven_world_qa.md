# 第7章世界首版验证（开发候选）

2026-10-14。基于获批 `deaedaef051da3c11b496505b1976a17998d02e1` 契约。此处仅世界模块，不代替章节、战斗、存档总账或 GUI 验收。

## 实现

- 六主语义地图及钦察营外沿/偏帐两个子区，显式地理邻接、地形碰撞、语义入口。所有主线及 L03 入口均有可步行到达的实际位置。
- 三份粮据位于不同粮车/簿册操作点。读取与知识授权仍由 runtime action 事务负责；世界不直接授知识、XP、钱、物件。
- 四个受控会话：伏牛追踪、绝壁有序攀援、囚寨确认、安全岸双手折弓。全部采用四邻真实行走与就近交互、输入日志重放；不可输入 `success=true`。
- 史富通每次玩家行走/交互同时沿可达路径走一格，无强制等候计数。显示层短步动画独立于规则位置；没有把 helper 直接落到终点的成功条件。
- 深谷在玩家碰撞层及受控探索验证层均不可穿越。B04 控制撤离由战斗模块拥有；完整桥仅是战斗演出通道。断桥世界安全岸为 west，敌岸 east。
- 赵山死后仅伏牛本场遗体，不在后续营中复活；王可伤势按世界事务呈现，恢复能行动时取消卧姿；俘虏只在囚寨，获救后于安全岸。
- 手工绘制的像素/矢量开发候选：粮营帐篷/车轮/粮袋/三据，伏牛道路烧车，岩阶藤索，囚栅/拘束架，桥绳/板/两岸旗，军阵地格，偏帐床榻/书案。未使用生成图、Fal、3D 降采样。不是最终美术。
- 托书/托款/檐鸟不按雪名义 owner 出现随军复制品；断弓和遗物展示条件来自真实物件状态。
