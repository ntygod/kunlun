# 第十章机关验收（2026-10-21）

## 范围与实现取舍

`pz_ch10_wooden_ox` 对应 `ch10_repair_ox`，`pz_ch10_stone_array` 对应 `ch10_stone_array`。这两个可交互示意是为章节设计的有限教学模型，不宣称还原原著完整机械或武学，也不代替成品像素美术。入口冻结第十章、场景、行动令牌和存活梁萧；没有阿雪同行或先学 A04 的条件。模型不改 HP、MP、XP、物品和技能。木牛修好后的护送与乱石成功后的三月练武由章节运行时另行执行。

木牛：轴距从 2/3/4 格选择；两曲柄各四相，错开两相；2 筹和 3 筹货包分别放在非零 ±1..3 承重点，不得叠放。有效条件为轴距 3、相差 2、`2 × 轻包位置 + 3 × 重包位置 = 0`。左右镜像均可成功。必须再实际负载行走三步，每步两相同时前移一格。错误配置卡住但不损坏角色或货物。开始有效行走后需重试才能拆换配置。

乱石：7×5 格，三石分居第 2/3/4 列，可移到第 0..4 行并选 `/` 或 `\`。三股来势依次从左侧第 1/2/3 行向东进入。斜石按方向进行真实九十度反射，出上/下界才安全，右岸为调息区。每股安全来势只产生一次空隙，需玩家单独“调息一回合”，三次调息且三石都参与才完成。第一股发动即锁定布局；失败可重试，无人物资源惩罚。板面实时绘制预测路径，发动后保留实际路径。

三层提示后可请求单步或连续协助。协助通过普通合法命令推进而不直接写完成标记；记录包含 `assist_step_v1`，重试不能洗掉协助标记。连续演示在隐藏、暂停、失焦、Escape、F5/F9、退出及令牌变化时停止。达到 1024 条记录后可重试，压缩过的手动历史标为 unknown，不能冒充完整手工过程。内部压缩标记不可从公共输入提交。

快照与证明在冻结上下文下重新播放全部输入并严格比较最终状态。错误字段、未知操作、布尔冒充整数、分数、篡改状态、缺少历史和令牌不一致均拒绝。拒绝输入不改变快照；失败恢复不覆盖当前实例。
