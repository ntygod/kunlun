# V3 策划复算工具

`audit_v3.py` 用 Python 标准库读取八个 V3 分模块，输出 UTF-8 CSV 和 JSON，不修改原文。执行方式见根目录 README。

输出包含四角色 40 与 80 级成长、公式与属性表差异、未来技能引用、配音与美术动作对照、主地图面积、场景索引、80 级经验及首领等级草案、注明假设的受击压力例子。

脚本从第 07 模块识别当前等级上限，按 40 或 80 级制复算面板与逐级曲线，并检查经验节点、首领详表与总览等级、治疗公式是否误用显示等级。已经迁移到 80 级的首领等级不会再次转换。

动作名称不同需要人工判断是否同义。技能获得的战中步骤、剧情通关条件和完整战斗时长也需要人工或原型复核；脚本不模拟完整战斗。80 级 CSV 为审阅数据。

`verify_combat_rules.py` 对 `combat_rules.json`、06任务表、07技能表及八模块合并快照做交叉核对；覆盖42条指令的消耗/CD/准备阶段、14个授权节点、21章经验与16个首领入场检查点。有限参考场景检查原始伤害分担、AOE包计数、协力预留与退款、韧性/CD时间戳、非致命多次伤害和B12两次合招的协力流程。检查失败时退出码为1，结果写入 `combat_rules_verification.json`。

`combat_pressure_examples.csv` 使用当前关卡K、标准装备与续航参数；`combat_pressure_comparison.csv` 固定相同人物面板，对比旧K/旧被动回复和新规则。它们不是完整战斗伤害或通关时长预测。
