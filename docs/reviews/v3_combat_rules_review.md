# 昆仑 V3 战斗规则收尾复核

本轮将护卫、韧性、冷却、合招前置和数值遗留统一为 `combat_rules_v1`。编辑来源为 [06任务表](../design/v3/06_全流程主支线任务详表.md)、[07战斗数值](../design/v3/07_战斗角色定位与全技能数值详表.md) 与 [规则参数](../design/v3/combat_rules.json)，合并稿及HTML/PDF同步。人物80级裸装曲线和标准装备数值未改。

## 已统一的结算规则

| 问题 | 当前口径 |
| --- | --- |
| 低速角色护卫晚于敌招 | 准备阶段先于速度轴生效，扣消耗/CD并占一次正常行动；反击是该动作的兑现 |
| 援护重复减防、AOE重复代受 | 分流原始伤害，各分支只用自身DEF和护体一次；不连环援护，花生自身AOE包只计一次 |
| 持续减伤或免死无限叠加 | 同类护体取最高、上限60%；护盾上限受益者HP的20%；每人每战复苏、免死各一次 |
| CD与韧性各表口径不同 | T轮施放CD=c，T+c+1可再用；保护从T+1持续p轮，同一回合也不重复破招；易伤到T+1结束 |
| 合招取消后溢出协力或白得行动 | 预留2格仍占3格容量；取消只退一次，存活者自守仅保护后续攻击；每轮普通收益合计最多1格，合招不回协力 |
| 多段、额外行动无限回蓝 | 每人每轮所有回气合计最多12；多段按一次动作计；飞燕改为同动作追击，药香正常行动后最多一次 |
| 战前满蓝与战后回蓝重复 | 独立战斗开场满MP，多阶段不重置；取消战后MP奖励，技能按固定下限与最大MP比例较大者收费 |
| B11需要后章被动才能戒杀 | 全场规则覆盖普攻、武学、反击、持续伤害、机关；留1HP并失战，不再受击刷收益 |

概率命中、暴击、闪避改为明示的会心与诱偏状态。首领保护不被“强制”或合招绕过；剧情封功、破车和护送机关按独立目标推进，不借此取消首领所有攻击或重复发协力。

## 获得步骤与战斗目标

6组合招均有明确授权：CO_01在B02第二轮试用、CO_04在B12第三轮试用、CO_05在B11第二阶段试用，胜利固化；CO_02在B07前秘洞解经、CO_03在孤舟和解、CO_06在B16前梁云托付后正式取得。试用不以先通关为条件，快照重试与跳过演出均幂等发放。

杏林悬壶、龙须取气、回阳术、迷香与花生关键破器技均明确到首次需求之前；镇海印由主线重逢保证获得。R02不再是合招必需支线，R05不再叠旧版55%护体，R03战外回蓝与R08额外协力也已对齐。其余支线的探索提示和人物记事保留，未定义数值的记事不暗增战斗属性。

B03按四轮辨路、拆两处机关脱险，不再要求虚弱双人组先打空雷震；虚弱梁萧也不能用零MP合招绕过武学禁用。B12按两次医武封功获胜，首组三轮为教学，不要求三轮打掉10300HP。B15按净化、拆招与生存目标分段，天罚先试用再固化。B16撞车与终局弩机均有明确进度目标，无需清空47500具名总HP。

与配平有关的阵容同步：B04第一阶段梁萧独战、救回阿雪后双人；B05梁萧加场景工兵操作；B09梁萧、晓霜、柳莺莺，花生留庄；B16第一阶段梁萧、花生、云殊。

## 数值与经验收口

关卡防御标尺改为 `K=100+4×(power_level(关卡基准等级)-1)`，同场共用固定K，不随玩家额外升级追涨。回春与内功再生通常每轮2%，药香1%，被动回复总上限3%；桑树之约1%。镇海印改为50%原始范围分担与30%护体；仁心普度全队主动回复25%，每战一次。持续伤害按ATK系数并设首领1%HP上限，取消按首领大血池无限放大。

以下是同一76级人物、第20章装备下的单次受击对照，未计降攻、主动治疗或其他护体，目的只在检查被动回复是否盖过单次受击：

| 场景 | 旧规则受击 / 每轮被动回复 | 新规则受击 / 每轮被动回复 |
| --- | ---: | ---: |
| 梁萧、天行谐律；敌ATK400×2 | 199 / 460 | 364 / 30 |
| 花生、大觉心与镇海印；敌ATK430×2.2 | 68 / 410 | 237 / 102 |

新规则四人AOE示例中，花生自身一包加三名同伴各50%分担共受591伤害、内功回复102。此为固定假设下的压力样例，不是完整战斗结论。数据见 [压力对照](v3_numeric_data/combat_pressure_comparison.csv) 与 [含假设样例](v3_numeric_data/combat_pressure_examples.csv)。

21章经验账分配主线35750、机关8250、必经遭遇5500，共49500，单走主线达到76级；16条支线共5500，全内容55000达到80级。B03前发够25级所需6540XP，战后的机关经验不提前借用；16场首领都有入场发奖检查点，同章累计列不重复相加。第20章战前发1210XP，终局余波375XP。装备由必经任务供给，技能升阶与药品价格、每战使用次数也已明确。

## 实际验证与剩余边界

- `audit_v3.py`：27行里程碑与装备加总、80级曲线、10个经验节点、16场首领等级交叉引用均无差异；无主动技能跨章未来引用。
- `verify_combat_rules.py`：184项通过，包含42条指令、14个授权节点、章节与入场经验账、八模块合并一致性，以及援护/退款/CD/非致命等有限参考场景。见 [验证结果](v3_numeric_data/combat_rules_verification.json)。
- 合并稿、HTML及PDF按当前源文档重新导出，并检查改动章节的页面排版。

当前没有战斗引擎，尚未做全流程战斗模拟或实际试玩，战斗强弱、敌AI轮换和时长目标仍待实现后验证。本轮没有扩展处理美术动作ID、地图面积预算或无关原著校勘；这些仍见历史审阅记录。
