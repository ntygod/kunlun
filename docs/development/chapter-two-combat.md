# 第02章目标制遭遇与观势实装

日期：2026-10-13。此文记录实施裁决与测试，不修改V3权威原文。敌人面板/地图抽象/候选回合阈值均为可试玩实施参数，不称原著固定数值或最终配平。

## 交付与接口

- `game/data/chapter_two_encounters.json`：两场固定基准Lv4/Lv5目标遭遇；K不随玩家补支线升级追涨。
- `combat/objective_engine.gd`：继承CombatEngine，仅覆盖场景行动、特殊敌意图、目标胜负；复用准备/速度/CD/MP/伤害路由/非致命末端，不复制战斗引擎。
- `combat/objective_encounter.gd`：输入历史、失败重试、可重放收据与快照。
- `ui/objective_battle_panel.gd`：只读面板，不持有引擎引用，不接收/提交won开关。
- 普通 `BattlePanel` 援护目标排除自身，与内核合法目标一致。

构造：`ObjectiveEncounter.new(rules, runtime, encounter, party, attempt_id)`。

`get_view/set_command/can_resolve/resolve_round/retry/victory_receipt` 与既有EncounterSession兼容；`receipt()`为同义入口。`apply_input(action)`返回accepted/error，只编排场景行动，必须调用resolve_round才执行，不直接推进成功。输入支持action_id及该动作所需lane/target/item/destination，拒绝多余字段；可带当前revision拒绝旧UI回调。

面板render(snapshot, skill_data, can_resolve)，signals为input_submitted(action)、command_requested(actor,skill,target,revision)、resolve_requested、retry_requested、continue_requested、leave_requested。get_view.objective含summary和available_actions（label/input），get_view.skill_costs供武学菜单展示。受保护秦伯符以controllable=false参加伤害结算，但没有正常指令槽；晓霜与花清渊不作为敌我可伤害单位。

static replay_receipt(receipt,rules,runtime,encounter,party)必须由任务系统使用可信关卡与可信战前队伍调用；任务系统另核对receipt.attempt_id等于当前步骤token。重放自身无法知道调用方当前token，不替代该检查。收据包含全部逐轮输入、命令、引擎事件、最终人物与目标证据；全量重放后精确比对。不能只凭result或objective_evidence的布尔值领奖。

session.snapshot/restore同样从可信构造参数逐轮重放；坏输入、伪造状态、跳步或不一致终态不能恢复。revision是界面编辑游标，可以因合法改选而大于最短重放的游标，恢复时只接收非负整数；不参与胜负。中途编排与胜败终态均支持；不支持动画内动作中断快照。外界保存应使用session接口，不能直接写ObjectiveCore.state。

## 棋坳护恩：真实保护目标

梁萧单人可控，秦伯符为气血90的受伤者。何嵩阳5000HP是防止少年清空高手的开发参数，胜利完全不读其血量。何嵩阳每轮实际发出铁索动作，危险线左/右交替：

1. 玩家看到秦伯符所在侧与铁索扫过侧，可扶秦移到另一掩体；这消耗梁萧正常行动。
2. 也可站到当前铁索线引走攻击，梁萧按共享伤害公式实际代受。这不是免伤开关。
3. 错移到危险线或错误引索使铁索击中秦伯符，立即失败，不发收据。
4. 连续两次真实铁索动作完成、秦未被击中且梁萧仍存活，九如接索援手自动结算，何嵩阳退去；没有“九如获胜”按钮。

搬位全避伤与两次引索受伤均有合法胜路；按未能护住的真实损失判败。两次窗口来自章2内容契约的实施方案，不称原著指定回合数。左/右两条线路是战术空间抽象，未声称完整地形碰撞或场景演出已制作。

## 长亭解药：窗口、交换、服药与撤离

侦听→假投诚→制住→核药→交换→服药→阻追→移动撤离，每步都消耗本轮正常行动，敌人每轮有公开意图和结算事件。

- 蒙语侦听给出“投诚者从东侧近前”，先有情报才能接近。西侧在守军视线内，错误接近增加警觉并触发真实敌伤害；不足三次仍可改走东侧挽回。
- 东侧接近只打开下一轮一轮的制住窗口。玩家等待/改做其他行动会错过，守军实际反应后窗口关闭，必须重新接近。
- 窗口内制住脱欢不扣其HP，也不等同打倒。药瓶在固定石凳交换点，要先核对药物；青瓶正确、红瓶不符。错误药瓶失败，不以按钮直接得到有效药。
- 解药必须实际喂给花清渊，剂量消耗；错给梁萧即浪费解药并失败。
- 服药后有明确追兵来路。正确栈道阻追得到有限撤离轮数；错误内庭设阻不能凭空延缓追兵。
- 离镜追赶延迟遵循源场景短促演出，仅记录导演事件，不提供伤害动物目标或操作教程。
- 内庭→栈桥→出口，或内庭→侧径→栈桥→出口，两条可行路线。移动须相邻，直接从内庭提交出口无效；轮数耗尽会被追兵赶上而失败。
- 所有人类敌人伤害通过共享非致命门，致命事件留1HP并失战。制倒谈判对象导致交换目标失败，不能清敌换皮通关。

花清渊服药前有到第13轮的恶化界限，总场景最多18轮。这些都是候选平衡参数。成功需要真实情报、时窗制住、有效交换、正确服药、阻追与到达出口；失败/重试清空本次输入历史，不产生胜利凭据、XP或物品。

## LX_A01 Lv1/2、破算、明心与LX_P01

运行技能observe映射LX_A01；party可传skill_ranks:{observe:1或2}、passives:[LX_P01]。能力是否获得由章节任务系统决定，两战都发生在九算之前，不应提前授Lv2或P01。

- 观势0MP/CD0、速度+15、不造成伤害；回复4MP进入统一每轮12预算。
- 破算持续施放轮T和T+1，不叠层；只在目标已有有效破招易伤时增加10个百分点。它自身不制造破招、不取消意图、不发协力。
- 明心只存一枚，下一次正常攻击消耗；本动作多段共享1.50倍率。反击不消耗；没有随机暴击。
- Lv2观势在执行后提供本轮20%护体，与自守/援护/现有护体取最高，T末到期。没有回滚先于观势发生的伤害。
- P01首次开战为最高威胁目标自动破算一次，不再多发明心、MP或破招。最高威胁定义为已公开本轮各段原始ATK×倍率之和；无公开伤害按0，同值按稳定敌槽位选首个。这是待后续AI配置丰富的显式实施裁决。
- MP严格高于最大值50%时，非准备的正常武学技能速度+6；普通攻击、自守、准备反制、场景行动不加。按锁轴前MP判定，不在支付费用后重排队列。
- 第02章九算完成授观势Lv2，第十算接纳后授P01，按内容skill_transactions分开落实。Lv3与其他终极技能未本章授予。
