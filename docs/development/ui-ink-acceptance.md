## 失败、环境告警与缺失前置

- 最初4d3f3c0导入因Skin与引擎类型重名失败，已修复，保留历史失败。
- 旧第一轮广泛选择章节测试时，缺失output/cache与CH11/CH12/CH13_SOURCE等历史存档，引发错误和超时；这些不是通过。新运行器在执行前逐项记录blocked及缺失路径，绝不伪造自然档，也不把未执行项目加到通过数。第04章已有合法命令生成入口的测试允许走原fallback，但明确不是自然档覆盖。
- 本地QA输入包未含docs/design，数据验证不能完成；完整仓库的该项以GitHub Actions实际执行为准，不拿game里的规则副本伪造设计源。
- Mesa/Xvfb有精确的“无法切换VSync”环境警告；原始日志保留，报告单列environment_warnings。只有原生截图阶段允许这一条已知驱动限制，其他ERROR、SCRIPT ERROR和WARNING仍使检查失败。不能声称日志完全无警告。
