## 本批代码：基础战斗面板可用性

涉及 `game/scripts/ui/battle_panel.gd`，不涉及战斗公式、存档协议、奖励、剧情或第14/15章内容。

已从基线代码确认的问题与本批修复：

1. 技能按钮与已编排行动只查五项硬编码名称；运行数据已有 `observe.name=观势察机`，却会显示内部ID。改为运行数据名称优先、旧基础名称回退。
2. 目标下拉框只在提交时记录选择。选择第二名敌人后切换招式会重建控件并丢失尚未提交的选择。改为即时记录，按角色和目标类别保留界面偏好；目标死亡后回退到当前合法目标。
3. 选择招式时销毁有焦点的按钮。改为仅在原焦点属于该面板时恢复到替换后的技能按钮，不抢占其他控件焦点。
4. 战斗结束、未选目标、空技能列表及过期角色回调缺少界面层防护。增加只读前置检查；真实命令仍交由原会话校验和结算。
5. 战报直接显示 `break/induced/counter`。这三项改为中文显示，不改事件类型或战斗数据。

界面偏好仅存在于面板实例，不写入战斗快照或存档。未知目标类别不默认为自身，而是没有可选目标；本批不擅自扩展目标规则。

新增 `test_battle_panel_usability.gd`，覆盖数据名称、未提交目标、敌/友/自身切换、角色间偏好、过期控件信号、焦点保持、不抢焦点、死亡目标、版本号、真气/冷却限制、空目标、战斗终态和只读性。测试通过控件信号和场景树检查行为，不等于操作系统层面的自然键鼠验收。
