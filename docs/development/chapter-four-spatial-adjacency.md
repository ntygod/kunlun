### 自然 GUI 阻断与本轮修复窗口

冻结版自然流程在背负入口发现真实软锁：普通移动以 `[553.75,310.42]` 一类半径内小数坐标完成骑行，随后受控会话继承该偏移格系；16 像素步进只能到 `[233,246]` 等位置，距目标超过 8 像素，因此无法交互。原现场与输入记录保留在 GUI 验收缓存，不纳入源码提交。此问题使旧冻结版完整主线 GUI 验收中止，不能将此前头部流程或旧地图自动测试视作新版完整验收。

本轮规则：普通 action 仍以真实 proof 的地图、路径进度、可行走位置及目标半径严格验证；验证成功后，下一受控段采用该 action 明确的 `geometry.position` 入口格。自由导航仍保留实际位置，控制器不接收调用方任意坐标。骑乘结束时，同一匹胭脂的位置由同一已验证终点派生。章4 `auto_world_entry` 在步骤激活时直接进入可信受控会话，控制器承担实际走位和交互；普通机关仍需到实物入口。完成时先同步已验证最终会话位置，再保存，避免旧世界坐标覆盖终点。

马的首次窗外等待点与地图静态实例统一为 `[48,240]`，沿六个真实相位到 `[144,240]`。显式“等胭脂靠近”每 0.2 秒最多追加一个原有合法 wait 输入，可取消；菜单、读档、重新激活、失焦和退出停止，抵达只停止等待，不自动跃窗上马。单步等待保留。旧章4开发 checkpoint 因地图版本改变重新生成；已发布旧章0—3不受影响。
