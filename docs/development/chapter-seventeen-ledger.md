## 失败与修正记录

- 初版应用测试有4项读档返回机关面板失败：恢复本身正确，但返回行走态而非正在操作的面板。仅第17章启用`resume_puzzle_panel`能力，让普通F9回到已保存的机关；原章节默认流程不变。复测302项零失败。
- 初版战斗测试错误地要求软索取消狼群意图的同轮立即发生狼噬。实际取消动作不应执行。保留旧失败，改为下一合法轮验证真实狼群伤害，未削弱保护/取消规则。复测118项零失败；之后追加实际战败、败局恢复、空奖励收据及战前资源重试20项，独立复测138项零失败。
- 原生大窗口初版机关仅有控件、留白过多；增加只读屋架/证据连接图，小窗口隐藏图示保留全部操作与提示。它不是新增地图成品美术。
- 现有字体缺少少数生僻字，改为语义相当的运行文案，不改源策划和字体文件。
- Xvfb/Mesa的精确VSync不可切换告警单列保留，其他WARNING/ERROR/SCRIPT ERROR仍使执行失败；不声称原生日志全零告警。

## 复验

```sh
python game/tools/validate_chapter_seventeen.py
python game/tools/develop/run_checks.py --godot /absolute/path/to/godot --output /tmp/kunlun-develop-evidence --native
```

运行器先生成序章至15的合法模型源档，再通过第16章实际命令生成第17入口；每次执行独立XDG，writer/reader为不同进程。默认同时回归原公共底座、14/15受影响功能、16与17。带`--native`的Linux执行需要Xvfb并用Dummy音频，原生日志与PNG保存在输出目录。生成模型入口不能替代原云端历史自然存档。
