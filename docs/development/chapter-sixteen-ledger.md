## 已遇失败及修正，不计为通过

- JSON整数/浮点的`[-1,-1]`出生哨兵比较导致合法部分档拒绝，改为逐数值判断。
- 原试配夜战在真实携伤入口失败；调整普通敌人开发参数，未新增入场/战后救济回血。
- 本章重试generation属于活跃输入证据，终章不应与无该历史的摘要比较；仅终章清除此临时字段，保留提示与实际结果。
- 晚章的“阿雪空席”插入了记事正文之前，旧UI按子节点序号找正文失效；改为按`InkPageDescription`语义节点找正文，空席仍保留。
- 小窗口横向按钮开启自动折行却没有最小宽度，截图发现窄条；补最小宽度/横向分配与结构断言。
- 初版跨进程测试的局部变量类型推断报错、数据验证器错误读取地图width字段均已改正；相应失败日志保留，不属于生产游戏通过证据。
- 首次原生运行未指定音频设备，容器ALSA报错；后续明确`--audio-driver Dummy`。原生Xvfb/Mesa仍有一条无法切换VSync的已知告警，单列保留，不冒称所有日志零警告。
- 扩大到每个动作都触发完整旧章校验的UI测试执行较慢，曾中止该轮；最后限定代表性E提交，其余动作仍检查真实空间入口并走模型事务。完整自然路线及持续保存性能不视为已验收。

## 可复验入口

```sh
python game/tools/validate_chapter_sixteen.py
python game/tools/develop/run_checks.py --godot /absolute/path/to/godot --output /tmp/kunlun-develop-evidence --native
```

脚本先生成合法的0—15章模型终档，再运行本章和受影响公共回归；每个执行有独立XDG，writer/reader为不同进程。保存退出码和引擎诊断，除了原生截图的精确VSync环境告警，其他SCRIPT ERROR/ERROR/WARNING都判失败。`--native`需Linux Xvfb，不使用系统音频设备。测试输入、图板演示与自然GUI证据严格分开。

## 合入门槛与剩余工作

开发分支接入不等于通过main合入门槛。第14/15原未验的完整自然GUI范围仍未被本轮模型回归替代。第16仍缺完整OS键鼠主线、全部选择/战术、持续存档性能、成品像素人物/地图/动作、音频及发布导出。主修学科的终局数值效果待契约补齐；第17—20章未实现，不能从章节16结尾直接跳成全游戏通关。
