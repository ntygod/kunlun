# 第六章世界开发候选

九张640×384逻辑图，共用320×180 nearest-neighbor世界与独立中文UI；并非原著全地形或最终美术。

## 运行

`godot --path game res://scenes/chapter_six_world_preview.tscn`

使用独立XDG数据目录。此入口不运行campaign，不写正式存档或奖励。

- `[` / `]`：九图自由探索；WASD/方向键实际行走。
- Tab：顺序切九个受控目标。每次使用标明的开发物品前置fixture，不冒充主线已取得物件。
- 受控时方向键每拍16像素，E实际交互，Space等待一拍，O查看操作提示，R从可信本段起点重试。
- F5/F9是本入口的内存快照/重放恢复；主流程磁盘保存另由main负责。
- 深水、墙和实心工料不可通行。浅水仅涉水惩罚；足点与金圈同一坐标源。

## 目标与控制

1. 阿雪：160,240取同一套拓本，256,240诵前两幅及两轮观察呼吸。梁萧安卧，不产生额外拓本或恢复量。
2. 梁萧：352,240先看岩中铉元剑、握柄、实拔。无`owner=ch06_plum_rock,state=lodged`唯一剑拒开始。
3. 梁萧：160/240/320,240三处旧物，可任意次序E调查。已看标记转绿。
4. 修屋：144,240取茅料，224,240取旧刨，304,240加工，等阿雪逐格走到336,272收拾床铺后完成。
5. 制桶：176,240取桶板，224,240取旧刨，304,272装配，阿雪同样实际到场后完成。两分支不互相伪造另一修缮。
6. 取竹：160,240及208,240各取一段，256,240破篾。
7. 阿雪：352,240取柴，384,240添火，416,240安放同一缺口碗。
8. 泡篾：从224,272走到272,304，浸泡/翻动/捞起同一束。缺一束实际材料拒开始。
9. 阿雪借料：432,304当面问四婶；464,304取铁箍；496,304取牛皮；400,272放回修造台。

三旧物、修缮和灶棚属于同宅相邻分区；库存canonical ID由runtime统一，地图仅投影。普通入口按chapter_six_runtime节点逐项绑定；父书三页同一书案，所有route末点等于E点。离村石桥160→320→464,240；不可逆确认和道别归runtime，地图不提前移除阿雪。
