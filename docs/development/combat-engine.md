# 确定性战斗内核：第一切片

日期：2026-10-13。权威规则仍为V3第07模块及combat_rules_v1，本文件记录工程实现裁决，不修改设计原稿。

## 已实现范围

`game/scripts/combat/combat_engine.gd` 是不依赖场景树、帧时间、随机数或动画完成回调的 RefCounted 内核。

- 任意数量参战者的逐人指令编排，三人独立指令测试；目标阵营、在场/失战、可用技能、剧情武学禁用、MP、CD验证。
- 回合初发布确定性敌人意图；编排不扣费；全部可行动队员提交后才能执行。
- 自守/单体援护/镜心准备先于速度轴；准备消耗正常行动，反击是其兑现。
- 单体原始伤害分流，每个分支仅使用自身DEF与最高护体一次；多段共享一个援护令牌；不连锁援护，普通AOE不触发单体分担。
- 速度快照、固定同速排序；延后速度状态；伤害无随机浮动。
- 匹配诱导与打断标签、同轮不重复破招、下一轮开始的保护、破招易伤到T+1末。
- 费用向上取整、减耗封顶50%、CD按T+C+1、回气预算每人每轮12；实际援护与破招各自首次奖励。
- 精确到事件的HP/护盾损失日志、实际行动和准备日志；胜/败终态、版本化回合边界快照及重试。
- `TrainingBattle` 现为共享引擎的序章教学适配器，保留现有UI API。镜心教学不再自行模拟扣血与MP。

运行数据为 `game/data/combat_runtime.json`。梁文靖固定面板来自07，镜心成本/CD引用原始 `combat_rules.json`。基础普攻、自守、援护是通用动作；`test_interrupt` 为不授予教学角色的引擎测试专用指令，不能当作完整飞星九宫剑。对手为明确标注的教学夹具，不冒充原著首领；它的高HP仅保障“两次诱导”的既有教学目标，不作为正式关卡配平。

## 公共API

- `CombatEngine.new(rules, runtime)`：深复制输入配置。
- `start(encounter, party)`：开始独立战斗、满MP、发布首轮意图并保存入场检查点。
- `get_view()`：返回状态深副本供UI显示，不可由视图改动内核。
- `validate_command(actor_id, skill_id, target_id)`：空串表示合法，否则返回稳定错误ID。
- `set_command(actor_id, skill_id, target_id, revision=-1)`：可改选；相同指令幂等；可选revision拒绝过期视图。
- `can_resolve()` / `resolve_round()`：只有完整编排才执行；完成一个整轮后进入下轮编排或结束。
- `snapshot()` / `restore(data)`：严格版本及嵌套数据校验；拒绝时不改变当前状态。
- `retry_checkpoint()`：恢复本次 `start` 的入场快照，不重发历史日志或重叠资源。

状态的 `round` 是全战轮次；`ready`、`protected_through`、`vulnerable_through`与状态 starts/expires 全部使用明确时间戳。事件ID从1连续增长；恢复快照同时恢复完整日志与序号，因此同样命令可产生完全一致的事件与终态。JSON解析数字可为浮点表示，但计数等字段要求整数值。

当前 `actor_by_id` 返回内核可变对象，供内核与测试使用；UI应使用 `get_view`，不得借此绕过编排校验。快照是受验证的本地检查点数据，不是联网反作弊协议。

## 明确的工程裁决

1. 同速时按开战队列的稳定槽位：队伍顺序在前、敌人配置顺序在后。准备也用该顺序，不依赖Dictionary迭代或浮点随机。
2. 速度轴在所有准备结束后一次锁定；之后施加的速度状态只从下轮开始生效。
3. 同一敌方动作内全部伤害段使用同一护卫令牌。护卫倒下后的后续段不再分担；已分流的包永不继续找第三护卫。
4. 当前支持每名敌人一个主动作的显式循环轮换，每轮发布意图前按固定队伍槽位顺移失效目标；执行前目标才失效时也按同类合法目标顺移，并写明重定向事件。尚未实现完整敌AI的战术选靶与联动规则。
5. 镜心反制等待指定敌人尚未执行的点名；该敌意图失效时在普通时序兑现普通掌。保护期仅35%护体，不诱偏；伤害后仍只兑现一次普通掌。
6. 已失战单位不再受击、反击或行动；本切片只实现HP归零失战，非致命留1HP属于后续全局伤害门。
7. 只支持编排边界与结束态快照，不支持动画中途/动作队列中途保存。暂时只有开战检查点，不能宣称多阶段战败续关。
8. 当前敌人动作未配置联动，同一方最后成员倒下判负；复杂同时胜负、护送失败与剧情目标优先级必须逐关声明。

## 教学变化与保留的验证

旧教学把镜心当作无伤计数，扣10MP后为70。现在它实际成功破招并兑现反击，按07获得6MP，所以第一轮为76MP。原476项基础检查全部保留，只将这一MP数值断言按权威规则改为76；第二轮自守仅回8MP（不是旧教学无条件额外+4），受最大MP限制仍为80。镜心命中还施加下轮25%降攻。

教学仍需镜心、自守、镜心三轮获得胜利，实际敌意图受首轮破招后的保护限制。正常使用UI无需任何新增剧情奖励；没有给梁萧发序章XP。没有修改story/save/main事务代码。

## 未完成，不得声称完整战斗

- 三人编排目前有内核与自动测试，游戏界面仍是单人序章教学；正式三人UI待接入。
- 42技能、6合招、装配与成长运行系统、等级覆盖、完整心法/被动未录入。
- 重击回气（单敌动作实际损失超过20%HP的+3）尚未接入；现有回气仅普攻4、自守/援护8、实际援护4、破招6及统一预算。
- 汇涓积层/AOE代受、镇海印、紧急替换护卫、免死/复苏、主动治疗、DOT、盾值授予/替换/时限、反伤、会心、完整减益组与驱散尚未实现。
- 本切片已有盾值吸收，但没有提供完整盾授予规则；不能凭输入shield字段声称护盾系统完成。
- 协力预约退款、剧情试用授权/固化、非致命B11、多阶段继承/检查点、场景机关进度和任务奖励桥接尚未实现。
- 5类破招中的点穴/截脉/破器尚未按各自完整效果上线；测试interrupt只证明打断时序与35%替代攻击。
- 敌意图未展示完整UI标签与关卡来源卡；未做16首领、54遭遇、真实胜率与战斗时长配平。
- 07的九宫步“1回合持续/下一轮速度”矛盾未静默改稿；正式技能录入时需拆分当轮护体、次轮速度或确认设计。
