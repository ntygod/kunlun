# 第05章世界局部操作开发候选

2026-10-14。13幅640×384逻辑像素语义图，15个逐格局部会话。不是原著完整面积或成品地图；场景为程序绘制的明确占位，阿雪和柳背梁使用已审人工像素候选。取盒在六锁秘库，开盒在天圆地方室，物件奖励/角色受伤/离队由runtime独占。

## 接口与空间约束
- `ChapterFiveWorldActions.begin(id, attempt_id, trusted_context)`；`apply_input/get_view/snapshot/restore/receipt/get_receipts/replay_receipt`沿章4。静态重放返回实际receipt或空字典。
- context含actors/items/world_objects/choices/completed_receipts/map_id/scene_id/objective_id/control_actor_id/carrying_pair；`world_objects.ch05_spatial_state`承接已验证收据。普通动作在真实E半径验证后，由runtime归约到其明确格点，再进入特殊会话。
- 全部spawn/锚点/行动脚点是16格点。特殊会话由可信entry自动开始，不先走最终点再倒退。跨视角不继承其他角色的光标：仅同map、同control_actor_id继承player_position。
- `actor_positions`记录实际角色位置。阿雪受胁带人必须继承small_hat_dropped_verified收据中的梁位置；无合法前态拒绝开始，不能把梁倒回树洞床。阿雪从本人入口步行到梁，再带到交接点。
- 小笠唯一点352,240。回收要求已有item_ch04_small_willow_hat，owner=ch05_thorn_hat/state=placed/location=map_ch05_tree_hollow及真实position。不存在时不能凭按键生成。
- 梁受限掉笠视角不能自由行走，公开view不包含柳/云殊或隐蔽角色位置。runtime决定何时展示半句及柳独立真相对白。
- 输入仅move(dx/dy单位正交)、interact、inspect、wait、retry。任意position/success/额外字段拒绝；日志4096，满后retry仍可恢复。途中JSON存读逐命令重放，未知附加命令或伪造状态拒绝。
- 守卫射线由实际位置/朝向与墙体相交决定，移动中同拍换格/线段接触均发现。失败不改HP，R恢复可信起点。
- 普通探索背负移速65×0.7；浅水另有0.5罚，L01只移除涉水罚。受控局部操作为离散步进，不宣称已有完整连续动画。
