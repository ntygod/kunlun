# 第16章来源对照与实现决定

适用：`develop` 上的第16章《西方昆仑》开发候选。授权来自2026-10-22用户的“继续开发剩余章节”，取代旧台账“第15章不启动16”的阶段限制，不改原V3八模块。

## 来源与范围

04卷 SC-16-01～04，06的MQ-16六步骤与PZ-07，07的LX_A06及80级成长，08的地区色板与独立高清UI为基准。运行数据记录四个源文件SHA256；`python game/tools/validate_chapter_sixteen.py` 检查未漂移。对白为明确标注的开发改编，不宣称逐字移植或成品演出。

16个场景、13张开发路线图、64个事件步骤覆盖：黄河开仓/治水，故居追思，三处水势观察后悟汇涓，精绝救风怜/驯马赠马/安置妇孺/夜战/葬礼，剑谷拒剑与辞别，兰娅重逢/生命天平/三年研学，埃及残像/七载行旅/十年东归。第17—20章未接入。

## 结算与成长

采用现行`combat_rules_v1`。最低入口40970XP，主线655 + 两个PZ-07结算1500 + 普通夜战100 = 2255，最低章末43225XP。三年书窗是互动时间演出，不另造第三笔PZ-07经验。

主线655XP的事件拆分属于运行层预算分配；总数来自现行预算，不代表原文逐事件指定。赠马、赠火石/算筹不创造货币。旧物逐项保留；风怜与兰娅不占战斗槽，不进入核心成长账。晓霜与花生的经验继承沿用已存在公共核心成长规则，不把他们拉进梁萧的西行战斗。

“汇涓成河”仅第一重：准备阶段，自身架势，本轮减伤50%；按单个敌动作的段数积1～3层，全部实际伤害结算后反震一次，倍率1.3+0.3×层数，最高2.2。韧性保护期不触发有效破招；反击次数/回气/被动治疗继续服从公共上限。已承受伤害不会因后续破招回滚。MP18或14%上取高，CD3。不得提前获得LX_A07/A08或新内功。

夜战是无编号普通遭遇，不是第17章B13。敌方1500HP/175攻击/140防御/48速度和轮换属于开发配平：基于真实最低入口携伤639/2551HP验证两套合法四槽。早期1800HP/275攻击并加杂兵的试配失败，已保留失败记录；没有以入场或战后无依据回血掩盖失败。后续仍须完整战术与真人试玩。
