## 下卷剧本总纲：从仇恨的囚徒到天心月圆

下卷对应原著《天道》卷及《劫波》卷尾声，主线流程约 **11.75 小时**，涵盖 **27 场核心重头戏（SC-15-01 至 SC-20-05）**。经历了钱塘丧侣、大都丧母与紫竹林死别的梁萧，在此卷彻底挣脱门户之见、家国狭隘与个人恩怨的泥淖。

在叙事结构上，下卷呈现**双线并进、万里远行、故人重逢、悟道止戈、舍身成仁**的五重推进：
1. **双线互证的道义之光（第15章）**：百丈坪上群豪以大义之名行私刑之实，明三秋、秦伯符、九如、花生舍命护友；东线花晓霜在无梁萧庇护之绝境中独撑危局，以《青杏卷》医理配合花生大金刚神力智破贺陀罗，废武而不杀，立住医道止戈的崇高风骨。
2. **万里孤旅与生命天平（第16章）**：梁萧自星宿海溯源悟“汇涓成河”，经精绝绿洲战火，抵马拉加天文台。在纳速拉丁遗留的“生命天平”前，他以自身鲜血证悟“人命至重，众生平等”，随后三年苦读、七载游历地中海残垣，于苍茫孤寂中洗尽眉间戾气。
3. **天山重逢与师道传承（第17至18章）**：瀚海风雪中重逢已成为小禽村首领的柳莺莺，天池畔刮须释怀，成全风怜叩首拜师；黄河东归途中，九曲阁扣质暴露出宗师未泯的任性，开封铁塔之战后由弟子风怜当面谏止师尊，完成两代人精神上的真正交接。
4. **括苍悟道与人剑相御·天罚（第18章末至第19章）**：误闻晓霜死讯令梁萧坠入心魔深渊，于括苍山漫天落叶与狂乱算式中参透阴阳相济的“和谐之道”；天机宫论剑，他断炎龙而不杀云殊，于巨字崖三轮运转中领悟欧龙子殉剑真意“人剑相御·天罚”，战平公羊羽与花无媸的太乙分光剑，迎来晓霜生还重逢、群豪封剑息争的澄明之境。
5. **石闸断后与江月留白（第20章）**：桑树下许下四愿温情未冷，元军铁骑已合围天机。梁萧以“人在书在”唤醒众人，为救门人毅然留身万钧石闸之外；晓霜含泪请云殊放闸，萧千绝在烈火箭雨中以身护徒、释怀坐化。终局定格于钱塘江口破晓微光，晓霜指尖探得那一线微弱心脉，花生西行、九如东去，唯余明月照大江。

- **场次编号**：SC-15-01
- **时间/气候**：暮秋清晨·浓雾锁峰、寒风萧瑟

- **可操作角色**：梁萧（行动受限状态：仅可进行视角环顾、受讯对答与内力调息）
- **知情范围**：公羊羽与花清渊认定梁萧身为大都统帅、附逆元廷，是破襄樊、屠常州的国贼，誓杀之以谢天下；明三秋与秦伯符深知梁萧在大都修《授时历》救万民之苦心，更惜其算学天资；梁萧自知双手染血、百口莫辩，面对师长亲旧心中唯余苍凉。

**【心理路程与戏剧张力】**
梁萧在此刻跌入人生的至暗时刻。双亲惨死大都的剧痛未消，胸前的玄铁囚龙锁沉重刺骨，四周皆是曾经敬仰的师长、同门以及打着“为国复仇”旗号的江湖群豪。面对千夫所指，他骨子里的孤傲使他不屑于乞怜辩解，甚至做好了以死谢罪的准备。然而，戏剧张力在明三秋与秦伯符的挺身而出中骤然爆发——明三秋哪怕被革除天机宫门墙、背负叛徒骂名，也要保住这旷古绝今的算学奇才；平日里脾气暴烈的秦伯符，竟不惜同室操戈护持晚辈。这份超越门户阵营的人间大义，在梁萧心底重重撞开了一扇窗：天下是非，绝非黑白二字所能道尽。
