## 第一部分：全局像素视觉规范与色板体系

### 1.1 核心画布、瓦片与相机视口规范

《昆仑》确立为**纯正手工绘制二维像素艺术（Pure Hand-Crafted 2D Pixel Art）**，严禁使用三维建模渲染转像素（3D-to-Pixel）、AI生成伪像素、非整数缩放旋转或破坏像素网格的实时法线体积光。全作美术通过严谨的工业化像素网格纪律，承载宋元山河的苍茫气韵与江湖儿女的细腻情致。

| 规范维度 | 技术参数锁定 | 引擎实现与美术制作纪律 |
| :--- | :--- | :--- |
| **世界逻辑画布** | `320 × 180 px`（16:9） | 世界层置于独立 `SubViewport (320×180)`；纹理过滤全局锁定 `Nearest-Neighbor`（最近邻点采样），严禁开启 Mipmap 与 Bilinear 滤波。 |
| **显示缩放策略** | 整数倍点对点缩放 | `1920×1080` 屏幕下执行 `6×` 无损放大；`1280×720` / `1366×768` 下执行 `4×` 放大并以 `#0D0F12` 玄青黑边画框居中承接；`2560×1440` 执行 `8×` 放大。 |
| **地图基准瓦片** | `32 × 32 px` | 单屏横向可视宽度恰好为 `10` 格瓦片（320px），纵向可视高度为 `5.625` 格瓦片（180px）。关卡路径宽度主干道定为 2～3 格，窄巷/栈道定为 1～1.5 格。 |

| **逻辑网格对齐** | `Snap to Pixel = True` | 角色物理坐标允许浮点运算，但精灵渲染坐标（Sprite2D Offset）与相机焦点（Camera2D）每帧强制向 `1px` 逻辑网格取整，彻底杜绝移动抖动与半像素撕裂。 |
| **对话安全构图区** | 底部预留 `48 px` 高 | 逻辑画布纵坐标 `Y ∈ [132, 180]` 为底部对话框覆盖区。触发剧情演出时，镜头自动平移使交互角色双足锚点处于 `Y ∈ [64, 124]` 的黄金视觉区，确保递药、执手等手部动作绝不被UI遮挡。 |

### 1.2 角色精灵容器、体态比例与双足中心锚点规范

为在 `320×180` 画布下兼顾“山川场景的开阔感”与“人物举手投足的戏剧表现力”，人物采用约 2.5 头身的写意武侠像素比例（摒弃 Q 版大头娃娃的滑稽感，强化肩背线条、衣袂垂坠与兵刃剪影）。

- **Y-Sort 动态遮挡铁律**：全场景所有动态角色（CharacterBody2D）、桌案、竹篱、树木、石碑等可产生前后遮挡关系的物件，必须将 `Pivot/Origin` 严格设定在物件与地面接触的底缘中心点。引擎按 `Global_Position.y` 实时逐像素排序。
- **脚底接触阴影（Contact Shadow）**：所有角色容器内自带半透明脚底椭圆阴影（尺寸 `16×6 px`，色值统一取当前地域色板最深冷灰并设 `Alpha = 45%`），置于角色图层最底层，腾空跃起时阴影停留在地面基准线并缩为 `12×4 px`。

### 1.3 四方向探索与四分之三侧向战斗舞台规范

1. **探索视角（Top-Down Oblique 45° 固定俯视）**：
   - **方向定义**：严格采用四方向绘制——南（`S`，正面向下）、北（`N`，背面向上）、西（`W`，正侧面向左）、东（`E`，正侧面向右）。玩家进行八方向斜向移动（如西南、东北）时，程序移动速度按 `×0.707` 归一化，动画统一播放水平侧向（`W` 或 `E`）行走序列帧。
   - **左右镜像不对称修正铁律**：严禁简单将 `W`（左向）精灵直接在引擎中勾选 `Flip_H` 充当 `E`（右向）终稿！导出图集前，美术必须针对右向帧手动修正三项宋元服饰与武侠特征：**① 衣襟交领必须保持“右衽”（前襟向右掩）**；**② 持剑/佩刀习惯手向保持一致（左手持鞘、右手握柄）**；**③ 单侧标志物（如梁萧右肩包袱、花晓霜左侧药囊、柳莺莺腰间右侧飞索钩、萧玉翎单侧发簪）必须符合空间翻转后的真实正背面遮挡关系**。
2. **战斗视角（3/4 Side-View 四分之三侧向固定舞台）**：
   - **阵位构图**：进入回合战斗后，无缝切入 `320×180` 侧向战阵舞台。己方最多 3 人居于舞台右侧（X坐标区间 `[210, 276]`，面朝左西 `W-SW` 四分之三侧向），呈前中后错落斜列；敌方居于舞台左侧（X坐标区间 `[44, 130]`，面朝右东 `E-SE` 四分之三侧向）。特殊剧情突围战（如雷公堡脱险、石闸断后）允许镜像反转阵位。
   - **刀光与内劲特效边界**：严禁全屏泛光污染像素动作。普攻与武学刀光特效严格控制在角色半身半径（`24×32 px` 至 `40×48 px`）以内，采用 3～4 色高对比无半透明硬边缘像素绘制（刀锋亮白 `#F4F7FA` → 剑气青锋 `#7CC7E8` → 残影深蓝 `#2C4A6F`）。
   - **寸劲帧（Hit-Stop）与震屏规范**：武侠打击感依靠“蓄势慢—出招快—击中顿”的帧间变速体现。重击命中瞬间触发 `2～4 帧（33～66ms）` 的受击双方动作定格（Hit-Stop），同时仅对 `320×180` 世界视口施加幅值 `1～3 px` 的整像素衰减位移震动，外层高清 UI 与字幕保持绝对静止。

### 2.1 像素肖像制作工业规范与差分管线

1. **画布与显示尺寸**：肖像基准画布为 `64 × 64 px`（含头部、颈部、肩线及标志性手部微势）。在 1080p 屏幕的高清对话框左侧以 `3×` 整数缩放（即 `192 × 192 px`）居中展示，衬以深灰微透底衬与 1 像素内描边金线。

## 第五部分：24组专属剧情情绪动作美术制作单（ACT-01至ACT-24）

### 5.1 叙事像素表演工业准则

1. **配额与帧数红线**：全作专属叙事表演动作严格锁定在 **24 组（ACT-01 至 ACT-24）** 以内，**每组上限 8 帧**。寻常对话一律使用四方向基础待机、朝向切换、半步位移、停顿留白与肖像差分组合呈现，严禁无节制派生一次性动画导致工期失控。
2. **动作母题回收（Motif Recycling）**：同一组动作骨骼通过**调整帧间停留时长（Frame Duration）**与**替换局部手持道具层（Prop Layer）**，在角色不同人生阶段形成戏剧呼应（如梁萧“伸出的手”由童年急切抢拽 → 青年挥斥画图 → 宗师停顿半拍后稳稳扶起）。
3. **容器与锚点**：单人表演使用标准 `32×48 px` 容器（双足锚点 `(16, 44)`）；双人相拥、搀扶、背负、挡箭等交互使用合成容器 `64×48 px`（主锚点 `(32, 44)`）。

#### 技术美术（TA）自动化管线校验与外包交付准则
1. **CI/CD 自动化美术扫描脚本（`art_sanitizer.py`）**：
   - **尺寸合规性检查**：自动检测导入的 Sprite 容器是否为 32×48、48×48 或 64×64，严禁非标准尺寸资源合入工程；
   - **色板越界扫描**：逐像素扫描 PNG 纹理，提取 Unique Colors。若存在超出当前地域 `PAL-xx` 索引色板或半透明过渡色（Alpha ∉ {0, 255}，除明确标注的阴影层外），阻断提交；
   - **锚点归一化断言**：静态检查所有角色帧的 Pivot 是否精准对齐 (16, 44)，浮点误差必须为零。
2. **外包制作验收三要素（P&P&P 准则）**：
   - **Proportion（比例严谨）**：无论何种角色体型，脚底接触面与逻辑像素格绝对平齐，绝不出现“浮空漫游”或“陷入地面”；
   - **Pacing（寸劲节奏）**：所有挥剑、出拳动画严禁匀速线性过渡，必须严格遵守“慢蓄势（120ms）→ 极速击出（40ms）→ 寸劲定格（80～120ms）→ 顺势收力（160ms）”的时序骨架；
   - **Poetics（武侠意境）**：克制全屏高光与五彩斑斓的魔法粒子，刀光止于半身，剑气取水墨青霜，将情感留给人物动作的停顿与眼眸微光。
