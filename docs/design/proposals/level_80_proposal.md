# 昆仑 80 级成长方案草案

建议把等级上限改为 80，主线正常通关约 72 至 76 级，全内容达到 80 级。80 级的作用是细化成长节奏，战力终点、剧情技能和内容规模沿用当前设计，再单独调整已发现的战斗失衡。

按 V3 主线 40 小时估算，通关 38 级约每 65 分钟获得一级，通关 76 级约每 32 分钟获得一级。实际升级应分散到场景目标、机关、阶段战斗和章节里程碑，避免把数级集中在章末弹出。等级不必每次解锁新技能，剧情悟招继续按人物经历发生。

本方案的成长公式与经验总预算已纳入 V3 第 07 模块，复算记录见 [80 级数值复核](../../reviews/v3_level80_review.md)。CSV 用作策划复算参考，章节内经验分配和游戏运行数据尚待实现。行动时序、续航和解锁前置按 [初稿审阅报告](../../reviews/v3_numeric_review.md) 随对应系统处理。

## 保持战力终点的成长公式

设当前等级为 `L`，等级上限为 `C`：

```text
t = (L - 1) / (C - 1)
x = 39 × t
power_level = 1 + x
基础属性 = floor(a + b × x + c × x²)
```

`t` 在 0 至 1 之间。四个角色的 a、b、c 沿用 V3 第 07 模块，但先修正表格的取整错误。40 级制中 `C=40`，80 级制中 `C=80`，因此两个版本的初始与满级基础属性完全相同；80 级提供更细的中间台阶。

| 梁萧裸装属性 | 当前 40 级终点 | 原公式直接算到 80 级 | 归一化后的 80 级终点 |
| --- | ---: | ---: | ---: |
| HP | 2316 | 5960 | 2316 |
| MP | 193 | 345 | 193 |
| ATK | 333 | 840 | 333 |
| DEF | 207 | 532 | 207 |
| SPD | 62 | 112 | 62 |

完整四角色逐级基础值见 [40 与 80 级成长对照 CSV](../../reviews/v3_numeric_data/normalized_growth_40_80.csv)。原表的标准装备与阶段心法按剧情进度获得，不能每升一级再加一套装备数值。

所有带角色等级的治疗与合招公式也使用连续的 `power_level`，只在最后结算时向下取整。例如捻针推宫改为 `floor(0.85 × ATK + 12 × power_level)`，保持原来 40 级终点的治疗基准。不能只改属性公式而保留 `12 × 显示等级`，否则治疗的等级项仍会翻倍。

阶段限定角色保留原固定面板，只换显示等级；技能升阶、装备门槛、归队补偿与首领推荐等级都应使用相同的映射，不单独乘二。

## 可复算的有限经验预算

先用一条容易校准的线性升级成本：

```text
从 L 升到 L+1 所需 XP = 100 + 15 × (L - 1)，L 为 1 至 79
达到 L 级的累计 XP = 100 × (L - 1) + 15 × (L - 1) × (L - 2) / 2
```

| 目标 | 累计 XP |
| --- | ---: |
| 20 级 | 4465 |
| 40 级 | 15015 |
| 60 级 | 31565 |
| 72 级 | 44375 |
| 76 级 | 49125 |
| 80 级 | 54115 |

完整阈值见 [80 级经验 CSV](../../reviews/v3_numeric_data/experience_80_draft.csv)。全内容经验预算先设为 55000，保留约 885 XP 的分配余量，达到 80 级后经验停止累加。

| 来源 | 预算 XP | 占比 | 发放口径 |
| --- | ---: | ---: | --- |
| 必经主线目标与章节里程碑 | 35750 | 65% | 含剧情首领结算，避免再重复计首领 XP |
| 必经机关与格物目标 | 8250 | 15% | 分配给八个必经机关及必经勘查步骤 |
| 常规必经遭遇战 | 5500 | 10% | 按实际必经遭遇分配，不靠重复刷新 |
| 16 条可选支线及其探索奖励 | 5500 | 10% | 相处记事和信物仍是主要奖励 |
| 合计 | 55000 | 100% | 不新增刷怪区域或剧情章节 |

在这个草案口径下，主线路径含必经机关与遭遇战共获得 49500 XP，达到 76 级且距 77 级仍有余量；全内容达到 80 级。若部分遭遇或格物改为可选，应从主线预算补足其 XP，避免无意中把通关等级绑定到支线完成率。不要直接把这四个总额均分给章节；应按首领入场节点检查累计经验，再分到章节内的多个目标。

技能 Lv.1 至 Lv.3 的强化独立于人物等级，用少量剧情节点或固定秘籍升级。先列出每次升阶的获得任务及成本，再决定是否需要额外货币，防止 80 次人物升级变成 80 次技能点菜单操作。

## 引入方案时的最少验证

1. 40 与 80 两版的所有角色初始和满级基础值一致，所有含等级项的治疗保持同一终点。
2. 不做支线的必经路径经验足以达到各首领推荐区间下沿；离队归队按照章节基准补齐，剧情技能仍按事件获得。
3. 用早期单人战与后期医坦组合验证目标回合数、失误代价和真气取舍，尤其检查反击、代受与无敌的重复触发。

前两类静态数据可由现有审计脚本复算；第三项需在战斗原型可运行后验证。等级调整本身不增加地图、敌人模板、肖像或动作组配额。
